## 🎯 Featured Projects

### 1. **Customer Propensity Modelling**
Developed an ML-powered propensity model to predict purchase likelihood using historical customer data.

- **Tech Stack:** Python, scikit-learn, Flask, AWS EC2, GitHub Actions, Docker
- **Key Features:** RFM feature engineering, model training/prediction pipelines, CI/CD automation, Flask API, containerized deployment
- **Impact:** Enables marketing teams to identify high-intent customers for targeted campaigns
- **Links:** [Repository](https://github.com/prxdyu/) | [Demo](#)

### 2. **Patient Stay Forecasting System**
Built an automated prediction system for hospital patient length of stay using production ML infrastructure.

- **Tech Stack:** Python, XGBoost, AWS SageMaker, Snowflake, SQL
- **Key Features:** EDA on historical patient data, GBDT regression model, SageMaker inference pipeline (24/7), model drift detection, automated retraining
- **Impact:** Helps hospital resource allocation and capacity planning
- **Links:** [Repository](https://github.com/prxdyu/)

### 3. **News Article Search Engine**
Built a semantic search engine using transformer embeddings and approximate nearest neighbors.

- **Tech Stack:** Python, SBERT, ANNOY, Flask, AWS, Docker, GitHub Actions
- **Key Features:** Sentence embeddings, ANN indexing for fast retrieval, Flask API with web interface, containerized deployment, CI/CD pipelines
- **Impact:** Retrieves relevant articles in milliseconds with semantic understanding
- **Links:** [Repository](https://github.com/prxdyu/) | [Demo](#)

### 4. **Market Basket Analysis - Product Recommender**
Developed a recommendation engine using market basket analysis to boost cross-sell and upsell.

- **Tech Stack:** Python, Apriori algorithm, Flask, AWS EC2, Docker, GitHub Actions
- **Key Features:** Association rule mining, recommendation pipeline, Flask API, automated deployment, CI/CD
- **Impact:** Helps marketing and product teams recommend relevant products to customers
- **Links:** [Repository](https://github.com/prxdyu/) | [Demo](#)

### 5. **approxKD - Python Package**
Published a Python package for Approximate Nearest Neighbor search using KD-Trees.

- **Tech Stack:** Python, KD-Trees, pytest, GitHub Actions, PyPI
- **Key Features:** Customizable distance metrics, comprehensive testing, automated packaging and deployment
- **Impact:** 100+ downloads, used in recommendation engines and similarity searches
- **Links:** [GitHub](https://github.com/prxdyu/approxKD) | [PyPI](https://pypi.org/project/approxKD/) | [Docs](https://prxdyu.github.io/approxKD)

### 6. **Pradyu Blogs - Web Application**
Built a full-stack blog application with user authentication and database management.

- **Tech Stack:** Python, Flask, HTML/CSS/Bootstrap, PostgreSQL, Render
- **Key Features:** User authentication, CRUD operations, responsive UI, database integration, cloud hosting
- **Links:** [Repository](https://github.com/prxdyu/)
